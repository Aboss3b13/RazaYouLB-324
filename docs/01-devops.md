# DevOps

## Was ist DevOps?

DevOps setzt sich aus **Dev**elopment (Entwicklung) und **Op**eration**s** (Betrieb) zusammen.
Es ist eine Arbeitsweise, bei der Entwicklung und Betrieb eng zusammenarbeiten und
möglichst viele Schritte automatisiert werden.

Betroffene Bereiche:

- **Planung** – Anforderungen erfassen und verwalten (GitHub Issues)
- **Entwicklung** – Code schreiben, Versionierung mit Git
- **Build** – Anwendung automatisch bauen (Vite)
- **Test** – Tests automatisch ausführen (Vitest)
- **Release** – Artefakte erstellen (ZIP, Docker-Image)
- **Deployment** – Anwendung automatisch ausliefern (GitHub Pages)
- **Betrieb & Monitoring** – Anwendung überwachen, Feedback sammeln

## Warum ist DevOps wichtig?

- Fehler werden **früh** gefunden, weil bei jedem Push getestet wird.
- Neue Versionen kommen **schneller** und **zuverlässiger** zum Benutzer.
- Weniger manuelle Arbeit = weniger menschliche Fehler.
- Alles ist **nachvollziehbar** (wer hat was wann und warum geändert).
- Das Team arbeitet mit den gleichen Prozessen und Werkzeugen.

## CI / CD

- **Continuous Integration (CI):** Jede Änderung wird automatisch gebaut und getestet.
- **Continuous Delivery / Deployment (CD):** Jede erfolgreiche Änderung wird automatisch ausgeliefert.
